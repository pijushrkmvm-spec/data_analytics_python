# Project: Data analytics using Python libraries
A comprehensive data analytics overview of public sales data using python libraries

# Dataset used:
https://github.com/pijushrkmvm-spec/data_analytics_python/blob/main/diwali_sales_data.csv

# libraries used:
1. Pandas
2. Matplotlib
3. Seaborn

# Project learnings:
* Performed data cleaning and manipulation
* Performed exploratory data analysis (EDA)
* Extracted crucial customer insights by identifying potential customers across different states, occupation, gender and age groups
* Identified most selling product categories and products, which can help to manage inventory and improve customer experiences
